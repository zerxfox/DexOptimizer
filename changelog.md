v9.0.0

🔧 Рефакторинг ядра (backend)

• Вся общая логика shell-скриптов вебрута (compile.sh, clean.sh, profile.sh, update.sh) вынесена в новый общий файл webroot/lib.sh: логирование, локализация (t()), парсинг числовых значений, сортировка пакетов по размеру, разбиение на воркеры, компиляция/сброс профиля, запись статистики. Дублирование кода между скриптами устранено.

• Автономный бинарник system/bin/deop (запуск через su -c deop) переписан в том же стиле, но общий lib.sh не подключает — часть логики (парсинг, разбиение на процессы, компиляция) в нём продублирована заново, а не переиспользована.

• Число параллельных процессов теперь ограничивается диапазоном 1–25 через clamp_parts() (в v8 в CLI-меню было ограничение 1–10, а в веб-скриптах компиляции ограничения не было вовсе).

• Добавлена функция has_internet() — переиспользуемая проверка соединения вместо инлайнового ping в разных местах.

🐛 Исправления в update.sh

• Раньше UPDATE_URL запрашивался дважды (отдельно за version, отдельно за zipUrl) — теперь один JSON-ответ переиспользуется для обоих полей.

• Раньше файл $ZIP_FILE создавался пустым до загрузки, из-за чего проверка [ -f "$ZIP_FILE" ] могла быть true даже при полностью упавшей загрузке. Теперь файл предварительно удаляется, а после загрузки проверяется [ -s "$ZIP_FILE" ] (не просто существование, а непустой размер) — так ловится и обрыв закачки, оставляющий 0-байтный файл.

• Добавлена явная проверка интернета в начале (has_internet) с локализованным сообщением об ошибке.

• Добавлена ранняя проверка, что JSON вообще получен (wget не вернул пустоту).

🌐 Backend вебрута (oresty.conf)

• Новый эндпоинт /dex_optimizer/stats — считает статистику на стороне сервера (Lua) и отдаёт готовый JSON: количество оптимизированных приложений, число запусков, прирост скорости (speedGain, % к предыдущим прогонам компиляции), процент успешных dex-компиляций (dexPct) и массив точек для графика (до 30 последних прогонов компиляции).

• Новый эндпоинт /dex_optimizer/last_run_time — отдаёт таймстамп последнего запуска из stats.txt.

• Новый эндпоинт /dex_optimizer/update — запускает update.sh по POST-запросу прямо из веб-интерфейса (раньше обновление запускалось только вручную/по расписанию).

• Обработка отсутствующего лог-файла исправлена: раньше при io.open с ошибкой "No such file" отдавался 500, теперь корректно отдаётся 204 No Content.

🎨 Веб-интерфейс (webroot)

• Удалены зависимости Chart.js, chartjs-adapter-date-fns, chartjs-plugin-zoom и Hammer.js (4 файла). График статистики теперь рисуется собственной лёгкой функцией drawChart() — простые столбцы (bar chart) без сторонних библиотек, что заметно уменьшает вес webroot.

• index.html, script.js, styles.css существенно переписаны (сотни изменённых строк) — под новую логику графика, серверные эндпоинты статистики и доработку UI/тем.

• Кнопка/логика обновления модуля теперь дёргает новый /dex_optimizer/update эндпоинт вместо прежнего способа.
